Focus area

Occupational exoskeletons, described the same way

Studies that put a device on a worker are indexed with the device, its actuation and supported body region, the study design, and the outcomes actually measured — muscle activity, kinematics, assistive forces, metabolic and cardiovascular cost, performance, and comfort. Evaluations that are otherwise scattered across journals become directly comparable.

Model library

The models and methods of the field, indexed the same way

From the classic assessment methods — the NIOSH lifting equation, RULA, REBA, the strain index — to biomechanical models of spine loading and fatigue, vision models that read posture and risk from video, and wearable-sensor models driven by IMUs, insoles, and biosensors. Each entry links to its paper, its source code where released, and the software that implements it where one exists.

Where this is going

  1. Now

    Gather what already exists

    Index public datasets, models, and analysis tools for occupational biomechanics under one schema, so a researcher can find and compare them instead of rediscovering them one paper at a time.

  2. Next

    Develop and publish our own open-source tools

    Release the analysis code this catalog is built to feed — pipelines for optical motion capture, egocentric video, and exoskeleton evaluation — openly, with the datasets they were validated on.

  3. Long term

    A community resource for evaluation standards

    Support shared standards for how occupational exoskeletons are evaluated and reported, and make occupational biomechanics analysis reproducible across labs.

How it works

Indexed metadata

Every dataset is described with the same schema — tasks, modalities, subjects, sampling rates, formats, and license — so you can compare before you download.

Links to the source

We point at each dataset's own repository (Zenodo, Dryad, institutional archives). Data stays with its authors, under their license.

Machine-readable

Each library is one JSON file — catalog.json and models.json — plus schema.org markup for Google Dataset Search. Read the docs.

Contribute

How to contribute →

The catalog is maintained in the open, and it grows through the community it serves. Propose a dataset, model, or tool, improve an existing record, help shape exoskeleton evaluation standards, or build the platform with us — every record is one YAML file on GitHub, and adding or fixing one is a pull request.

About this catalog

This is a discovery index for the occupational biomechanics community — human-motion datasets today, with models and open-source analysis tools being added. Each entry describes a resource and links to its original source; listing is descriptive and is not an endorsement. Datasets keep their own licenses, and access terms are set by their authors. The catalog is maintained by the AnyMotion Lab.

Know a dataset, model, or tool we should list — or want to work together? See how to contribute, or email the link and a short description and we will add it.
